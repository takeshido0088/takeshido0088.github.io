プライバシーポリシー

対象: 台所タケシ道 チャンネル分析ツール（以下「本ツール」）
最終更新日: 2026年11月10日

1. 本ツールについて

本ツールは、YouTube チャンネル「台所タケシ道」（@kitchen_takeshido）の運営者が、自分のチャンネルの数字を読むためだけに使う個人用のツールです。使うのは運営者本人だけです。

2. 読む情報

本ツールは、運営者が許可した Google アカウントについて、次の読むだけの許可（スコープ）を使います。

  • youtube.readonly: 自分のチャンネルの動画の一覧・公開状態・再生回数などを読む
  • yt-analytics.readonly: 自分のチャンネルの視聴回数・視聴時間・視聴者維持率などの分析の数字を読む

ほかの人の個人情報は集めません。視聴者一人ひとりを見分ける情報も扱いません（YouTube が出す集計済みの数字だけを読みます）。

3. 使い方

読んだ数字は、運営者が自分の動画の出来を振り返り、次の動画を作るためだけに使います。広告・販売・第三者への提供には使いません。

4. 保存と共有

  • 許可の情報（アクセストークン・リフレッシュトークン）は、運営者のパソコンの中にだけ保存し、外のサーバーには送りません。
  • 読んだ数字は、運営者のパソコンの中の記録として保存します。第三者に売ったり渡したりしません。

5. Google API のデータの扱い

本ツールが Google API から受け取った情報の使い方と、ほかのアプリへの受け渡しは、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。本ツールは YouTube API サービスを使っています。YouTube 利用規約と Google プライバシーポリシーも参照してください。

6. 許可の取り消し

許可は、Google アカウントのサードパーティ接続の設定からいつでも取り消せます。

7. 問い合わせ

問い合わせは、YouTube チャンネル「台所タケシ道」の運営者まで、Google Cloud の同意画面に書いたサポートメールアドレスでお願いします。

Privacy Policy (English)

Kitchen Takeshido Channel Analytics ("the Tool") is a personal, read-only tool used only by the owner of the YouTube channel "Kitchen Takeshido" (@kitchen_takeshido). It uses the read-only scopes youtube.readonly and yt-analytics.readonly to read aggregated statistics of the owner's own channel and videos. It does not collect personal data of anyone else. The data is used only by the owner to review their own videos; it is not sold, used for advertising, or shared with third parties. OAuth tokens and the data read are stored only on the owner's own computer. The Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The Tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google Account permissions.
