台所タケシ道 チャンネル分析ツール

このツールは、YouTube チャンネル「台所タケシ道」（@kitchen_takeshido）の運営者が、自分のチャンネルと動画の数字（再生回数・視聴時間・視聴者維持率など）を読むためだけに使う、個人用のツールです。

使うのはチャンネルの運営者本人だけです。一般の方が使うためのツールではなく、ログインや登録の受付もしていません。

できること

  • YouTube Data API で、自分のチャンネルの動画の公開状態と再生回数などを読む
  • YouTube Analytics API で、自分のチャンネルの視聴回数・平均視聴時間・視聴者維持率などを読む

しないこと

  • 動画やチャンネルの設定を変える・投稿する・コメントする・削除すること（読むだけの許可しか使いません）
  • ほかの人のデータを集めること

プライバシーポリシー

Kitchen Takeshido Channel Analytics (English)

This is a personal, read-only tool used only by the owner of the YouTube channel "Kitchen Takeshido" (@kitchen_takeshido) to read the statistics of their own channel and videos (views, watch time, audience retention, etc.) through the YouTube Data API and the YouTube Analytics API. It is not offered to the public, does not change any channel settings, does not post, comment or delete anything, and does not collect anyone else's data.
